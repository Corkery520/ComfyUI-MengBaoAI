# 保存与预览图片节点

`萌宝AI·保存图片` 和 `萌宝AI·预览图片` 共用同一布局：图片占位区、批次切换、提示词来源选择、两个并排入库按钮及状态文字。生成结果直接显示在占位区，不再在按钮下方重复显示原生预览。空图时两个按钮禁用，图片保持比例完整显示，不裁剪。

- **加入素材库**：保存当前显示图片的原始文件，通过现有素材库接口校验大小并持久化，保留原图尺寸和 Alpha 通道。不会使用提示词缩略图代替原图。
- **加入提示词库**：携带当前图片的像素缩略图和对应提示词打开入库表单，确认后保存。多个提示词来源时先选择来源；没有关联提示词时可以在表单补充。

占位区是只读结果预览，不是新的上传入口。提示词表单现有的文件选择、拖拽及 `Ctrl+V` 图片上传功能保持不变。

节点名称、输入标签、按钮和占位提示跟随 ComfyUI 中英文设置；原始 HTTP、文件和素材库错误保留英文。入库时禁用两个按钮和图片切换，避免重复请求；完成或失败后恢复操作并显示状态。

内部节点 ID、输入、原生保存与临时预览行为以及 PNG 工作流元数据均不改变。预览节点仍使用 ComfyUI 的临时文件；需要长期保存的图片应使用保存节点或加入素材库。

更新前端脚本后按 `Ctrl+F5` 刷新 ComfyUI。已有画布节点会在重新加载时使用新的布局。

## 检查

```powershell
node --test tests/test_frontend_image_output.mjs
python -m unittest discover -s tests -p 'test_image_output.py'
```

前端测试覆盖空白占位、图片替换、按钮位置、多图切换、当前图片入库、原图与缩略图分离、失败反馈、重复点击、中英文切换、API 子路径和缓存恢复。隔离预览可使用 `tests/preview_materials.py` 的 `/image-output` 页面，不读取真实密钥或调用付费 API。
