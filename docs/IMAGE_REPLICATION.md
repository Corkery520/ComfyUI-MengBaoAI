# 图片复刻

新增节点归属 `萌宝AI/电商`，跟随 `Comfy.Locale` 切换中英文。可搜索 MengBaoAI、MengBao、萌宝、图片复刻或节点的内部 ID。

## 接线与执行

```text
加载图片 IMAGE -> 图片反推 image
图片反推 analysis -> 图片复刻设置 analysis
图片复刻设置 prompt -> 图像生成 prompt
图片复刻设置 replica_settings -> 图像生成 replica_settings

可选检查：
图像生成 images -> 复刻检查 images
图片复刻设置 replica_settings -> 复刻检查 replica_settings
```

1. 在全局 API Key 管理节点保存密钥。视觉分析仅使用全局密钥，不读取工作流里的生图密钥。
2. 加载一张源图，点击反推节点的“识别图片”。该按钮只提交反推节点和必要上游；不执行下游生成或检查。图片批次会明确报错。
3. 点击“打开复刻设置”，查看原图编号框和对应元素。可添加、删除、移动、缩放元素，也可直接修改归一化位置。修改位置后必须点击该项的“确认位置”。删除项会在生成指令中要求移除并修复背景；删除产品同时移除其包装文字和 Logo 子项。
4. 按元素选择保留或替换。文字填写新文案，其他元素填写替换描述、参考素材或同时填写两者。读不清的文字和不确定项需人工核对。产品分组可联动替换同款产品，产品包装文字及 Logo 随目标产品更新。
5. 替换素材支持文件选择、拖拽及 Ctrl+V，支持从萌宝素材库选择。多个上传区域只接收悬停或焦点区域的粘贴；文本框保留原生文本粘贴。
6. “AI 产品描述”是一次额外视觉请求，只用于产品元素及其目标产品参考图，不读取原产品图片。重复点击会产生新请求；进行中按钮禁用。
7. 点击“确认设置”，再运行工作流。确认后继续修改文字、位置或素材会取消确认状态；未确认时不能提交生图。

“保存草稿”不会授权生图。原图变化后运行会要求重新识别；点击“重新识别”创建新任务，并重新从主模型开始。识别失败后的普通工作流运行不会自动重新提交付费请求。成功分析，包括备用成功结果，会被缓存，重复生图不重新反推。

## 素材与比例

原图固定为参考图 1，替换素材按元素顺序排列并按内容 ID 去重。各图片分别发送，保留原始宽高，不拉伸成统一尺寸的图片批次。不允许同时连接普通参考图端口；超过生成模型参考图上限时直接报错，不截断。

参考图上限包含原图：gpt-image-2 为 14，gpt-image-2.5 为 16，nano-banana-2 与 nano-banana-2-pro 为 14。设置面板按直接连接的生成节点限制素材数量；最终以后端模型校验为准。

默认采用最接近原图的模型支持比例，存在差异时提示。生成模型、数量及分辨率仍由现有生成节点控制。GPT 系列在复刻模式选择自动分辨率时，会落实为基础 1K，以满足固定比例的接口约束；选择 2K 或 4K 时保持所选档位。普通生图的自动规则不变。

位置框是画面摆放范围，不是产品真实尺寸。产品比例以目标产品主体为依据，不以含拍摄背景和留白的照片文件比例推断；空间不足优先等比缩小。未提供的规格、功效、认证及不可见信息不得编造。

## 主备视觉请求

- 主模型 `gem-3.7-flash`，备用 `gem-3.8-flash`。
- Gemini 原生接口：`https://api.lk888.ai/v1beta/models/{model}:generateContent`。
- 单次请求超时 180 秒。每个分析或描述请求最多调用主、备各一次，相同图片、提示词与原生参数，不循环重试。
- 连接失败、连接或读取超时、HTTP 429、HTTP 5xx、明确模型不可用时切换。密钥缺失、401/403、余额不足、参数错误、安全拒绝、无效分析 JSON 和取消不切换。
- 界面显示当前模型、原始切换错误及最终实际模型；两者失败保留各自英文错误并遮蔽密钥。超时不代表上游未计费，备用请求可能产生额外费用。

## 检查与持久化

复刻检查对每张成图核对目标文案及禁用旧文案，输出原图片和 JSON 检查报告。检查或视觉请求失败不会触发重新生图，也不会修改图像生成历史的完成状态。不确定的包装及艺术字仍需人工核对。

资源、识别缓存和草稿存到 `ComfyUI/user/mengbaoai/replication/`。工作流只保存编辑 JSON 和资源 ID，不嵌入完整图片或全局密钥；跨机器迁移时还需迁移对应用户资源目录。新节点 ID 为 `MengBaoImageReverse`、`MengBaoImageReplicaSettings`、`MengBaoReplicaAudit`，历史节点 ID 与输出顺序不变。

## 验证边界

自动测试使用模拟视觉响应，覆盖主备规则、请求缓存、位置和文案确认、产品联动、参考图顺序与原始尺寸、数量限制、草稿及素材接口、取消及检查失败保图。独立本地预览使用临时用户目录，不调用真实付费 API。真实接口的识别质量、计费和成图效果需另行授权测试；功能迁移不承诺像素级复原。
